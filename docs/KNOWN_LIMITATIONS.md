# Known limitations

1. Survivorship / frame. Only places printed as incorporated in census tables are observed. Settlements that never incorporated, which may include places the railroad bypassed, are absent, so "disappearance" cannot be studied directly.
2. Coverage gaps. 1920 is not digitised. 1930 and 1970 rest on one printing. 1890–1910 values are mostly single-printing (B); only ~100 were visually verified.
3. OCR error. Grade A values were 24/24 correct in a random check (95% CI ≈ 86–100%); B values 22/23. Errors remain possible.
4. Boundaries. Annexations and boundary changes are not harmonised.
5. Network timing. Atack dates are benchmark years (interval-censored). Nothing is observed between 1911 and 2020; abandonment dates are unknown. Positional error of hundreds of metres is plausible relative to a 2 km threshold.
6. Operators. Railroad names are present for only a few hundred Texas segments.
7. Controls. No agricultural output, county-seat status, oil discovery or highway-timing variables.
8. Identification. No design here identifies a causal effect. The 1890–1910 panel has 6 switching towns; matching has poor balance.
9. Hub definition uses 1910 counts ≥ 10,000 (grade A/B); results depend on that choice.
10. Sandbox constraints during the build. Several sources (UNL, Vanderbilt page, Texas Almanac, TSHA, TSLAC, NHGIS) could not be reached, which shaped the source choices above.
